## 🚀 安装

1. 在 Chrome 打开 `chrome://extensions`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹：`职投助手`。
5. 点击工具栏蓝兔图标，侧边栏会打开。

## 🧭 使用流程

1. ⚙️ 到「设置」填写 AI 地址、模型和 API Key，点击“测试连接”。
2. 📄 上传简历图片，点击“重新提取简历内容”，检查并保存。
3. 🔎 打开 BOSS 职位详情页或列表页。
4. ➕ 点击“加入投递清单”，或点击“分析当前岗位”生成招呼语。
5. ✍️ 在招呼语区域查看 JD 与简历匹配结果，必要时修改后重新生成。
6. 🚀 在投递清单点击“批量生成招呼语”，再点击“开始投递”。
7. ✅ 投递成功后岗位会记录到岗位库，可导出 Excel 兼容 CSV。

## 已实现

- BOSS 页面当前岗位信息读取（含 JD 的多选择器兜底）
- 用户自有 OpenAI 兼容 API：完整提取简历内容、JD 重点能力与简历匹配分析、招呼语生成
- 显式确认后的沟通按钮点击、文本发送与简历图片上传尝试
- 本地岗位库、去重与 Excel 兼容 CSV 导出
- 内置静态图文操作指南

## 注意

- BOSS 页面会更新，沟通输入框/上传控件可能需要随页面变化调整选择器。
- 简历和 API Key 均存于 Chrome 扩展本机存储；简历图片在解析时会发送给你配置的 AI 服务。
- 自动发送由你点击确认后才执行；发送完成后请在 BOSS 聊天页核对文字与图片状态。
